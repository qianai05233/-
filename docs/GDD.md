# 《雾境遗章》游戏设计文档 v0.1（GDD）

像素风横版动作肉鸽（Roguelite-vania），玩法对标 PC《死亡细胞》(Dead Cells)：
单局跑层、永久死亡 + 元成长、随机掉落与词缀、高难度快节奏 60fps 战斗。

## 1. 核心循环
进入 run → 第1层 → 清怪/开箱/拾取蓝图 → 层末传送门被「雾之封印」锁住 →
击败本层小 Boss 解封 → 传送门进入下一层 → …第5层 Boss → 最终决战（大 Boss）→
胜利结算：雾晶入账、蓝图解锁；**死亡任意时刻回结算页**，雾晶保留用于祭坛元升级。

## 2. 60fps 手感规范（硬性）
- 固定时间步 `dt = 1/60` 累加器模拟；渲染插值；目标真 60Hz。
- 土狼时间 0.08s；跳跃缓冲 0.12s；翻滚无敌帧 0.30s（前 0.1s 加速）。
- 攻击可取消窗口：前摇不可取消、命中后 0.15s 可取消入翻滚/技能。
- 命中停顿(hitstop)：小怪 60ms、小 Boss 100ms、大 Boss 140ms；屏震幅度按伤害分级。
- 飘字、残影、粒子、光效全部走独立 VFX 层（见 `assets/effects_vfx_sheet.png`）。

## 4. 小怪设计原则（每层 3~4 种，行为互补）
近战压制 / 远程牵制 / 突进骚扰 / 环境陷阱型各至少一类；同屏 ≤8 只；
精英变体 = 原帧表换色 + 词缀（迅捷/霜染/雷怒/吸血）。

## 6. 肉鸽系统（对标死亡细胞）
- **雾晶**：局内货币，死亡后保留 → 祭坛元升级（攻/血/翻滚/起始稀有度）。
- **蓝图**：局内拾取 → 结算解锁进掉落池（武器/技能/词条）。
- **武器池**：剑/弓/杖/匕/书 × 稀有度(白蓝紫金) × 词缀（霜/雷/吸血/迅捷/爆裂）。
- **血瓶**：每层上限+1 机会（开宝箱概率）。
- **随机性**：手工 tilemap 关卡 + 随机怪物配置/掉落/词缀/增益祭坛位置。
- **通关后**：解锁「深渊难度」（敌人+词缀、Boss 新招式），循环加难。

- 手柄：标准 map（A 跳 B 滚 X 攻 Y 技 LB/RB 切换武器）。
- HUD 完全复刻参考图 1 规范（见 `docs/reference/02_scene_hud_spec.md`）。

## 8. 数值锚点
玩家 HP 120(F1)→160(F3)→210(F5)；飘字基准 -32/-48/-76 为各 tier 普攻中值；
暴击 ×1.75；元素异常（冻/燃/感电）3s dot 或减速。

## 场景 01 迷雾森林·遗迹之境（第1层）
- 文案：「古老的森林在夜色中苏醒，迷雾中潜伏着未知的敌人……」
- 夜色迷雾森林 + 哥特遗迹剪影；敌人：兜帽幽魂、蓝色火焰怪；飘字 `-32`。
## 场景 02 水晶深渊·永冻之谷（第3层）
- 文案：「结冰的山谷之下，隐藏着更深的秘密……」
- 冰晶洞穴；敌人：冰傀儡、晶刺蛛；飘字 `-48`。
## 场景 03 暗影城堡·深渊回廊（第5层）
- 文案：「在无尽的黑暗中，你将面对真正的试炼。」
- 红月哥特城堡；敌人：持盾骑士、刺客暗影；Boss：白披风鹿角盔深渊骑士；飘字 `-76`。

## HUD 规范（三图一致，UI 复刻依据）
- 左上：圆形头像框 + `Lv.5` 角标；血条（斜切边金属框）数值例：120/120、160/160、210/210（随楼层成长）；血条下一排菱形能量水晶（4 格）。
- 右上：小地图框（节点+连线，当前层标注「第N层」）；其下任务目标两行：`✦ 击败所有敌人`、`✦ 获得 1/3 个宝箱`。
- 右下：菱形技能槽 ×3：Q（翼刃glyph）、E（剑气glyph）、第三格锁链锁定；槽上数字为充能层数。
- 飘字：白色像素数字 + 深色描边；暴击/受伤红色粒子。
- 左上角关卡标题样式：`01 迷雾森林·遗迹之境` 编号+副标题+两行描述文案。

## 视觉基调
冷调蓝紫夜色；技能/光效高饱和青蓝；敌对元素少量红色点缀；像素风、强轮廓光。
